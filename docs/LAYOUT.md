# popup v1.3界面结构

首要任务是快速继续观看。默认选中最近观看的分P，主界面仅一个高对比度主按钮。选择其他清单行只更换目标，不自动播放或修改进度。

固定400×520px：上方56px标题区，中间当前目标与搜索/分组清单，下方44px操作栏。主按钮48px，清单连续独立滚动、只绘制视口及少量预加载行，不再翻页。展开面板最大420px、内部滚动，不新增options页。超过1GB时显示提醒，主内容相应压缩，外部高度不增加。

标题区使用获批紫色B站电视/书签图标；右上角同套SVG均为32×32点击区、20×20图标，水平居中排列。

任意嵌套分组可独立折叠并记忆。较深层级缩进最多32px，完整路径在悬停与编辑下拉框中查看。搜索名称、原标题、分P或UP主时，临时展开匹配路径；清空搜索恢复折叠状态。

清单行常显编辑、删除。编辑保存名称与归属不改进度/书签。分组可改名、调整上级，禁止循环；默认组固定。删组先说明影响范围，将视频和待补全链接移回默认组，8秒可撤销。

添加面板顶部为醒目「添加当前页」，下方预填保存名称和默认分组；折叠的「通过链接添加」放在后面。两种方式都支持名称、分组、新建组和全部分P。

添加、书签、设置面板互斥。展开时主内容inert，避免键盘落到被遮挡控件；Escape或关闭可收起并返回入口。设置里的完成判定、清理和备份再折叠。

系统字体；主标题22px、视频标题16px、列表标题14px、主按钮16px；4px间距基准。当前封面80×48，列表封面56×36，固定占位、懒加载。默认青绿，可用预设、原生颜色选择器和HEX自定义；深浅色分别推导背景、选中行、正文与按钮文字，确保可读性。无装饰渐变或大阴影。

设置内实际使用Rare UI Theme Selector。保留官方源码，通过外层配置中文与三种选项、CSS适配尺寸。官方预览、radiogroup、方向键、Home/End与受控value均实际运行。

操作反馈还实际使用官方ToastCard，提供短暂图标入场/描边动画。清单保持原生DOM；React在设置或首次反馈时加载，两个入口共享框架代码，原生提示即时后备。减少动态效果偏好生效。测量报告列出新增体积、打开耗时和首次设置成本，不宣称零成本。
